# TDExtract web download

Download TDExtract-web.zip from this branch. Unzip and serve the folder with an HTTP server to play; opening index.html directly from disk is unsupported.

For browser-only play, enable GitHub Pages with GitHub Actions in the repository settings, then run the Build and publish web game workflow on main with Publish the playable website selected.

This download is the initial Godot prototype. Source and development instructions are on main.
